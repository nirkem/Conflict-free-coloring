This repository implement a simple Conflict-free coloring game.

**both methods required Google Chrome or another browser to load the game**

It can be opened by:

- Github pages(web):

  1. open link ---> https://nirkem.github.io/Conflict-free-coloring/

- Lcoal use:
  1. clone the repository using in cmd/powershell/bash:
     git clone https://github.com/nirkem/Conflict-free-coloring.git
  2. make sure you have Google Chrome downloaded on your PC
  3. open the file 'index.html' in the project folder.
