Conflict-Free Coloring

Source on GitHub

Enter a number of points to begin

Color points so that every disc containing any of them also holds a color that appears exactly once inside it.

How it works
  1. Draw random points, then generate a coloring.
  2. Each round, the algorithm picks points that are not neighbors in the Delaunay triangulation and gives them the next color. Higher colors come from later rounds.
  3. In any circle, the highest color appears exactly once. Draw one to check.
  4. The number of colors grows roughly like log n.
